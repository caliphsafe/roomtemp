# ROOM TEMP

A 43 Build interactive concept and partnership deck for Caliph, DJ Fresco, and Boogz.

## Run

No install or build step. Run `python3 -m http.server 4173` from this directory, or open `index.html`. JavaScript enhances the presentation; the core content remains available without it. `npm run check` verifies JavaScript syntax.

## Deploy

Static HTML, CSS, and JavaScript. Import this repository into Vercel with Framework Preset **Other**, no install/build command, and output directory `.`. `vercel.json` includes the static settings. No database, credentials, runtime services, or package lock are required.

## Contents

14 responsive chapters, chapter menu with direct links, previous/next and keyboard navigation, an interactive visual thermometer, selectable room zones, event timeline, partnership explorer, founders' field notes, itemized editable cash budget and door-revenue break-even calculator, and a print/save-to-PDF action.

The energy scale uses numbers and a thermometer, with no named tiers. Readings are a concept demonstration, not live telemetry. 97–100 is proposed as a rare distinction, subject to all-founder review and the four-dimension rubric in the deck. Future voting, live streams, partners, event date, and venue are not represented as launched or confirmed.

The revised planning model assumes no external DJ fee, unpaid promotional artist appearances, and admission at the door. Its $800 default consists of optional $150 equipment, $150 extra production help, $150 door/security contribution, $150 paid promotion, $50 supplies, and $150 reserve. Venue and other unpriced costs are entered as $0 pending agreement, not confirmed free. No sponsorship or bar revenue is assumed. The $25 admission price is illustrative. All cost lines, including the $0 DJ and artist defaults, are editable. Expected paid attendance defaults to 150 and can be changed independently of capacity and complimentary places. Revenue, fixed and variable costs, projected profit/loss, profit margin, break-even, and the sellout comparison update on every input. Profit is before unpriced costs and founder distributions; reserve is included conservatively. Amounts are calculated in cents, and invalid or over-capacity scenarios are clearly flagged. Reset restores the example numbers. Calculator assumptions are illustrative USD values, kept only in page memory. Inputs reset on reload. The founders' field notes are public presentation content, not a private document store. No personal, financial, or audience data is collected.
