# ROOM TEMP

A 43 Build interactive concept and partnership deck for Caliph, DJ Fresco, and Boogz.

## Run

No install or build step. Run `python3 -m http.server 4173` from this directory, or open `index.html`. JavaScript enhances the presentation; the core content remains available without it. `npm run check` verifies JavaScript syntax.

## Deploy

Static HTML, CSS, and JavaScript. Import this repository into Vercel with Framework Preset **Other**, no install/build command, and output directory `.`. `vercel.json` includes the static settings. No database, credentials, runtime services, or package lock are required.

## Contents

14 responsive chapters, chapter menu with direct links, previous/next and keyboard navigation, an interactive visual thermometer, selectable room zones, event timeline, partnership explorer, founders' field notes, editable illustrative break-even calculator, and a print/save-to-PDF action.

The energy scale uses numbers and a thermometer, with no named tiers. Readings are a concept demonstration, not live telemetry. 97–100 is proposed as a rare distinction, subject to all-founder review and the four-dimension rubric in the deck. Future voting, live streams, partners, event date, and venue are not represented as launched or confirmed.

Calculator assumptions are illustrative USD values, kept only in page memory. Inputs reset on reload. The founders' field notes are public presentation content, not a private document store. No personal, financial, or audience data is collected.

## Access and interactions

Semantic headings, native buttons and dialog, keyboard-visible focus, accessible names, pressed states, live announcements, reduced-motion support, and a print stylesheet. No emojis.
